# Дурак — веб-фронтенд

Браузерная копия клиента `DurakDotnet/DurakOnCSharp` на чистом HTML/CSS/JS
(без фреймворков и сборки). Используются **те же ассеты**, что и в оригинале:
спрайт карт `Cards.png`, рубашка `Back.png` и звуки `accept/invite/text/win.wav`.

## Запуск

Просто откройте `frontend/index.html` в браузере — сборка не требуется.

Либо поднимите прилагаемый сервер на Node.js (без зависимостей; отдаёт эту
папку, правильные MIME-типы, без кэша):

```bash
cd frontend
node server.js         # http://localhost:5500
node server.js 8080    # другой порт
PORT=9000 node server.js
```

Подойдёт и встроенный сервер Python: `python3 -m http.server 5500`.

## Что воспроизведено

**Главное меню (`MainMenuForm`):**

- вкладки «Найти игру», «Правила», «Повторы игр»;
- ввод имени (со случайной генерацией, как в `RandomNameGenerator`);
- список доступных игроков и кнопка «Пригласить» → `invite.wav`,
  ожидание с прогресс-баром, ответ бота → `accept.wav`;
- входящее приглашение с таймером и кнопками Да/Нет;
- список повторов с прогресс-баром загрузки.

**Игровое поле (`GameForm` + `SessionGraphics` + `SessionController`):**

- канвас 800×600 с тёмно-зелёным фоном, как `PictureBox`;
- рубашки соперника сверху, рука игрока снизу, 4 стопки по центру,
  колода с открытым козырем справа;
- перетаскивание карты мышью, выбор стопки, проверка правил
  (`CanPush` / `CanBeat`);
- кнопки «Грести» и «Отбой / передать ход» с теми же сообщениями;
- постраничный вывод руки (до 9 карт на страницу);
- таймер хода.

**Завершение партии (`TextAnimator`):**

- анимация «You Win» / «You Lose» шрифтом Times New Roman с белой обводкой,
  звук `text.wav`;
- конфетти в цветах из оригинала и звук `win.wav`.

**Повторы (`ReplayForm`):** просмотр сохранённых партий с шагом «назад/вперёд»;
повторы пишутся в `localStorage` после каждой завершённой партии.

## Структура

```
frontend/
├── index.html          разметка всех экранов
├── server.js           сервер для локального запуска (Node.js)
├── css/style.css       оформление
├── js/cards.js         спрайт карт, имена карт
├── js/engine.js        логика партии (порт GameSession.cs)
├── js/bot.js           ИИ соперника
├── js/render.js        отрисовка поля (порт SessionGraphics.cs)
├── js/lobby.js         главное меню (порт MainMenuForm.cs)
├── js/game.js          игровой экран (порт GameForm/SessionController)
├── js/replay.js        просмотр повторов (порт ReplayForm/Replay.cs)
├── js/audio.js         звуки (аналог NAudio/WaveOut)
├── js/app.js           навигация и модальные окна
└── assets/             cards.png, back.png, *.wav
```

## Отличия от оригинала

- Вместо TCP-соединения с `DurakSharpServer` — локальная партия против
  простого бота. Сетевая часть описана в `backend/openapi/`
  (микросервисы + OpenAPI).
- Формат карт (`suit,power`) и правила совпадают с оригиналом, поэтому
  логику легко переключить на серверные вызовы game-service.
